ClickyBot 0.1.61 fixes SAMPLE COLOR changing the area to watch. Color sampling now updates only the main rule's RGB values, leaving its watch/search coordinates, condition and reference image unchanged. SAMPLE GATE COLOR likewise updates only the gate RGB values; it preserves the gate area, reference, enabled state and whether an area has been selected.

Click a pixel or drag a sample area to read its center color. The selection overlay explains that existing areas stay unchanged. F8 and Ctrl+F8 retain their documented watch/gate area-selection behavior, without changing RGB. Selecting watch/gate areas and capturing references remain separate actions. Sampling from an image condition no longer redirects to changing its search area. Failed or cancelled samples retain existing settings.

Validation: production WPF selection handlers with deterministic successful/failed pixel reads across pixel, image and gathering conditions, main/gate sampling, selected/enabled and unselected/disabled gates, negative monitor coordinates, unchanged references and apply/save settings. Separate area-selection behavior, existing editor/updater, inspector and gathering/image/input checks pass without game input. Windows installer and portable package versions and contents verified.
