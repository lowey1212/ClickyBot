ClickyBot 0.1.51 changes Aion combat to use Tab first, then press 1 and hold LEFT mouse when the target indicator is confirmed. Automatic right-mouse camera turning is now disabled for new and existing profiles. The optional camera setting preserves previous pixel/direction settings and runs only after Tab finds no target.

Combat clears stale virtual mouse buttons when starting and releases held input on Stop, F7, cancellation, target loss or focus loss. Activity messages identify each Tab and 1 tap, held left mouse, and a failed target match. Saved watch areas and reference captures are preserved.

Validation: simulated production input sequence, default and legacy profiles with no right-mouse hold, optional camera ordering and release, target loss/reacquisition, focus/capture loss, cancellation, matching regressions and real WPF editor/inspector checks. Both installer and portable package built and verified. In-game behavior requires a user retry.
